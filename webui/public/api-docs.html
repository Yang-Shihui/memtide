REST API

Memtide 服务启动即提供全部 REST 接口（Docker 栈默认 :8300， 本地 python -m memtide serve（读 MEMTIDE_PG_DSN））。所有请求/响应均为 JSON。 每个端点卡片可直接展开并在线执行，查看真实响应。

鉴权：设置环境变量 MEMTIDE_API_KEY 后，所有端点需要请求头 X-API-Key: <key> 或 Authorization: Bearer <key>； 未设置时完全开放。本页执行时会自动携带浏览器里保存的 key。

写入 / 记忆 CRUD

POST/memories写入记忆（对话 → 原子事实 → 门控 → 冲突消解）
text 与 messages 二选一；支持 OpenAI content-parts（图片等）、调用方时间戳。
参数说明
text | messages必填二选一；messages 为 [{'role','content'}]，content 支持 parts（image_url / input_audio / file，可带 caption）
user_id / agent_id / run_id作用域隔离
timestampISO-8601，数据自身时间（导入历史对话），影响 created_at/valid_at/遗忘曲线
infer默认 true；false 或字符串 "false" = 原文直存
metadata附加到本批事实的对象
返回 added/updated/noop/rejected/gate 决策明细

      

    

  


  

    
GET/memories列出记忆

    

      
Query说明

        
user_id / agent_id / run_id作用域过滤

        
limit默认 100（上限 500，SQL 层生效）

        
include_invalidtrue 时包含失效/被取代记忆

      

      

        
含 attachments / metadata / 审计字段

        

      

    

  


  

    
GET/memories/{id}单条记忆

    

      
软删除的记忆默认 404；?include_invalid=true 可见。

      

        
把 {id} 换成真实记忆 id

        

      

    

  


  

    
PUT/memories/{id}修正文本

    

      
同步更新向量索引并记 UPDATE 审计事件；已失效记忆拒绝（防复活）。

      

        
{"updated": true}

        

      

    

  


  

    
DELETE/memories/{id}删除

    

      
默认软删除（invalid_at + 审计保留）；?hard=true 彻底删除。

      

        
{"deleted": true}

        

      

    

  


  
检索 / 记忆块


  

    
POST/search混合检索（向量 + BM25 + 实体 → RRF）

    

      
参数说明

        
query必填

        
user_id / agent_id / run_id作用域

        
limit / include_forgotten默认 10（上限 500）/ false（字符串 "false" 亦可）

        
memory_type / slot融合后过滤（fact/preference/episodic/procedural；slot 如 location）

      

      

        
components 含 rrf/semantic/bm25/entity/retention 得分明细

        

      

    

  


  

    
GET/context核心记忆块（注入 system prompt）

    

      
Letta 式常驻块：重要度 × 留存度排序的事实 + 与查询最相关的记忆。

      

        
{"context": "## Memory\n..."}

        

      

    

  


  

    
GET/history审计日志

    

      
全量事件（ADD/UPDATE/DELETE/ACCESS/CONSOLIDATE），带 prev/new 值；不带 memory_id 返回全库最近。

      

        

        

      

    

  


  
多模态 / 运维 / 反思


  

    
GET/media/{sha256}取回媒体素材

    

      
内容寻址原始文件（不可变缓存头）；sha256 来自记忆的 attachments 字段。

      

        
二进制；带 nosniff + attachment 头（控制台缩略图走 blob URL，不受影响；浏览器直开会下载）

        

      

    

  


  

    
POST/consolidate后台反思（聚类→概括→取代）

    

      
同主题 ≥3 条记忆蒸馏成概括，成员进 superseded_by 审计链。

      

        
报告 clusters / members_absorbed / summaries

        

      

    

  


  

    
POST/compact近重复压实（纯向量去重）

    

      

        
cos≥去重阈值的簇保留最优一条

        

      

    

  


  

    
GET/exportJSONL 导出

    

      
含审计状态与 embedding（base64）；媒体文件需随 media_dir 拷贝。参数：?include_invalid（默认 true）、?embeddings=false 省略向量、裸 ?download 触发浏览器下载。

      

        

        

      

    

  


  

    
POST/importJSONL 导入

    

      

        
lines 为 /export 的 JSONL 对象数组；冲突策略 skip|overwrite

        

      

    

  


  

    
POST/rebuild重建向量索引

    

      
更换 embedding 模型或向量库数据丢失后，从关系库全量回填。

      

        
{"reindexed": N}

        

      

    

  


  

    
POST/media/gc孤儿媒体清理

    

      

        
delete=true 才真删；默认只报告

        

      

    

  


  

    
GET/stats运行统计 + 后端信息

    

      

        
计数 / 事件分布 / 真实模型名 / media_files

        

      

    

  


  

    
POST/reset清空全库（危险）

    

      
删除所有用户的全部记忆，不可恢复。必须提交 {"confirm":"RESET"}，生产环境请配合 API 鉴权使用。
